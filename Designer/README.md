# CredVaultix 设计资产归档

本目录保存项目各阶段的界面效果图与设计源稿。目录格式为：

```text
Designer/<大版本>/<YYYY-MM-DD_具体版本>/<类别>/
```

类别说明：

- `readme/`：使用脱敏演示数据生成、可用于公开文档的正式截图。
- `ui-audit/`：开发过程中的界面与响应式验收截图。
- `playwright-captures/`：保留原文件名的自动化浏览器截图。
- `prototypes/`：可交互 HTML 设计源稿。
- `demo/`：动画演示文件。
